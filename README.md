# Bums — appens data

Dette repo rummer KUN det, iPhone-appen Bums viser: `events.json`, `manifest.json`, kort-billederne i `kort/` og eventbillederne i
`billeder/`. Det skrives hver nat af natjobbet som ét commit uden historik og serveres af GitHub Pages. Ingen mellemregninger, ingen
feedback, ingen rå sider.

Oplysningerne om arrangementerne er arrangørernes egne, som de selv har offentliggjort på deres egne sider. De er samlet her til appen Bums.
Koordinaterne (`lat`/`lon`) kommer fra OpenStreetMap: © OpenStreetMap-bidragydere, Open Database License (ODbL),
https://www.openstreetmap.org/copyright
